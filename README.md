# US Healthcare Analysis

##  Project Overview

This project analyzes US healthcare data to uncover patterns and trends related to **patients, hospitals, demographics, admissions, and billing**. The analysis focuses on understanding healthcare utilization and identifying factors that influence admission and billing costs.

## 🎯 Objectives

- Analyze patient and hospital trends.
- Identify patterns in healthcare admissions.
- Explore demographic characteristics of patients.
- Identify key factors associated with billing and admission costs.
- Generate actionable insights that can support healthcare resource planning and data-driven decision-making.

## 🛠️ Tools & Skills

* **Microsoft Excel**
* **Data Analysis**
* **Data Cleaning & Transformation**
* **Exploratory Data Analysis (EDA)**
* **Statistical Analysis**
* **Data Visualization**
* **Pivot Tables & Charts**

## 🔍 Analysis Performed

* Cleaned and prepared healthcare data for analysis.
* Analyzed patient demographics and hospital-related trends.
* Examined admission patterns across different categories.
* Investigated billing and admission costs to identify major cost drivers.
* Used statistical techniques to identify meaningful patterns and relationships.
* Created visualizations and summaries to communicate key findings.

## Key Insights

The analysis helped identify important patterns in **patient demographics, hospital admissions, healthcare utilization, and billing costs**. These insights can help organizations better understand demand patterns and support more effective resource allocation and planning.

##  Business Value

The project demonstrates how healthcare data can be transformed into meaningful insights that support:

* Better resource planning
* Understanding patient and admission trends
* Identification of major cost drivers
* Data-driven healthcare decision-making
